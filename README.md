# Wakeroo

A loud mission alarm clock for heavy sleepers. The alarm only stops after you complete a wake-up mission (math, shake, QR/barcode scan, typing, memory and more).

- Platform: Android (Google Play first)
- Stack: Kotlin, Jetpack Compose, Material 3
- Min SDK 26, target SDK 36, compile SDK 37

## Build

```
./gradlew assembleDebug
```

Open the project folder in Android Studio to run it on an emulator or device.
